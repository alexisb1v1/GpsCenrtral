Manual de Marca y Guía de Estilo: Vectura

## Identidad Visual

Vectura es un sistema de gestión de transporte urbano que proyecta profesionalismo, claridad y eficiencia. La estética es *limpia, espaciosa y ordenada*, evitando elementos genéricos y priorizando la legibilidad de datos operativos.

## Paleta de Colores

Azul Corporativo (Primary): #2563eb (Usado para acciones principales, branding y elementos de énfasis).

Fondo de Cuerpo (Background): #f7f9fb (Un gris muy suave que reduce la fatiga visual).

Superficies (Surface): #ffffff (Blanco puro para tarjetas y contenedores elevados).

Bordes/Divisores: #e2e8f0 o #f1f5f9 (Líneas finas y sutiles).

Texto Principal: #1e293b (Slate **800**).

Texto Secundario: #64748b (Slate **500**).

## Tipografía

Fuente: Inter (Sans-serif moderna).

Escala:

Headlines: Bold (**700**), tamaño grande para títulos de sección.

Body: Regular (**400**) / Medium (**500**) para lectura fluida.

Labels: Medium (**500**), tamaño pequeño (12-14px) para etiquetas de campos.

## Componentes y UI Elements

Contenedores (Cards)

Fondo: #ffffff

Bordes: 1px solid #e2e8f0 (Resaltados y limpios).

Redondeo (Border Radius): 12px (Inviolable para todos los contenedores principales).

Sombra: Sutil shadow-sm para dar profundidad sin ensuciar el diseño.

Padding: Espacioso (mínimo 24px en escritorio, 16px en móvil).

Botones (Buttons)

Primary: Fondo #2563eb, texto blanco, rounded 8px o 12px según contexto.

Secondary: Fondo transparente o gris muy claro, borde sutil, texto azul.

Interacción: scale-95 en click, transiciones suaves de color en hover.

Inputs y Formularios

Estilo: Borde completo, fondo blanco.

Border Radius: 8px.

Estados: Borde azul #2563eb en focus.

Labels: Siempre visibles arriba del campo, nunca solo placeholders.

Listados y Tablas

Estilo: Tablas minimalistas sin bordes verticales, solo divisores horizontales suaves.

Filas: Hover con cambio sutil de fondo (#f8fafc).

Acciones: Iconos alineados a la derecha con padding generoso.

## Iconografía

Set: Material Symbols (Rounded) de Google.

Estilo: Trazo consistente, esquinas redondeadas para suavizar la interfaz técnica.

## Layout y Espaciado (Desktop)

Ancho de Página: Full-width (Ancho total). Las pantallas deben expandirse para ocupar todo el ancho disponible del viewport, evitando contenedores centrados con márgenes laterales excesivos (estilo *boxed*).

Estructura: Sidebar fija a la izquierda y área de contenido dinámica que se ajusta al **100**% del espacio restante.

Grilla: Sistema basado en múltiplos de 8px.

Densidad: Baja. Se prefiere el *espacio negativo* para separar conceptos antes que líneas divisorias pesadas.

Navegación: Sidebar a la izquierda (Escritorio) con indicador activo mediante barra vertical azul y fondo sutil.
